## Decision
Build **"Working Memory"** as centrepiece and **"Build Tape"** on `/built` as second (zero-network) wow. Working Memory makes the Life Map show the agent working: each tool call lights a stream from its hub into the core with its real latency, Clopar points at one item by name, one approved card visibly moves money across the map. Confidence high on fit and 60 fps budget, medium on live model calling the right tools every time, hence a recorded-cue replay is part of the feature.

- "Hero number changes after cancelling subscriptions" is false: hero is `budget.flexLeft` (non-fixed categories only; subscriptions are fixed). What changes is the emergency-fund date (12 -> 11 months).
- No tool reads subscriptions.
- A proposal card is not rendered on Home (`pendingCard` only in map corner widget); the Clopar beat runs on `/`.
- `demo-seed.mjs` inserts into dropped `subscriptions` after `reset_my_data`.
